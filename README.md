## 数据与口径

- 白模：OSM 轮廓优先，3D-GloBFP / CMAB 补高度，地标按公开资料人工校正（每页「数据与口径」逐条列出处）。
- 周边配套、地铁、路网：OpenStreetMap；步行距离为 OSM 路网最短路估算。
- 本站不含高德数据（实时路况、路况快照与官方路况截图只在本机版）。
